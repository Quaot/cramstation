# Cramstation profiles
#
# [Name] starts a profile. [Name: Setup] adds a setup to it.
# A setup starts with everything in its profile, then adds its own lines.
# A profile with no setups opens as it is.
#
# Settings
#   root = Downloads\ECE 150     the folder other paths start from (inside your user folder)
#   notes folder = 2 Practice    where "notes" keeps answer files (default "2 Practice", else root)
#
# Windows are written as  side = what
#   side is left or right, or full for the whole screen.
#   Several windows on one side stack top to bottom.
#
#   notes                   Notepad with "<first PDF> - my answers (date).txt"
#   notes "file.txt"        Notepad with that file, made if missing
#   pdf "file.pdf"          one PdfCraft window with that PDF
#   tabs "a.pdf" "b.pdf"    one PdfCraft window, one tab per PDF
#   pick "folder" "file"    tick PDFs from these each time you open the setup
#   folder "folder"         File Explorer on that folder
#
# Paths go in quotes. A single path may skip them. * matches any text in a name,
# and %USERPROFILE% and other variables work.
